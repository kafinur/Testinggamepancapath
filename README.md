# PancaQuest Adventure — Semi-3D Web Prototype

Prototype web ini dibuat berdasarkan visual PancaQuest Adventure yang disetujui.

## Yang sudah tersedia
- UI game biru-modern yang responsif.
- Karakter utama siswa SMP bergaya semi-3D/2.5D berbasis HTML/CSS.
- Wajah, mata berkedip, rambut, seragam, backpack, shadow, dan animasi berjalan.
- NPC Nadia dan Pak Budi.
- Nadia memiliki animasi melambaikan tangan dan tanda quest.
- Lingkungan sekolah, perpustakaan, taman, pepohonan, lampu, bangku, jalan, dan mini-map.
- HUD nyawa, XP, progress level, misi aktif, pause, fullscreen.
- Kontrol laptop: WASD / Arrow.
- Interaksi laptop: E / Space.
- Kontrol HP: joystick analog virtual + tombol AKSI.
- Dialog NPC dan quest sederhana untuk pengujian.

## Cara uji
1. Ekstrak ZIP.
2. Buka `index.html`.
3. Gunakan WASD/Arrow.
4. Dekati Nadia dan tekan E/Space.
5. Di HP, gunakan joystick dan tombol AKSI.

## Tahap pengembangan berikutnya
Prototype ini adalah bahan website visual + kontrol karakter. Langkah selanjutnya dapat menambahkan:
- Level 2–4,
- mini-game,
- soal C4–C6,
- sprite/ilustrasi karakter yang lebih detail,
- audio,
- sinkronisasi skor ke PancaPath/Form B.
